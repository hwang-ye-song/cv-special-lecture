## 1. 느낀 점

### KPT

| Keep (유지할 것) | Problem (문제) | Try (시도할 것) |
|---|---|---|
| 특강을 녹음해 두고 전사본을 AI로 정리하는 방식은 계속 유지하려고 합니다. 녹음이 없었다면 보고서 작성과 복습이 어려웠을 것입니다. | 로그인 과정에서 어려움을 겪었습니다. 계정 인증 코드 입력 단계와 노션 인증 시 403 오류가 발생했습니다. | 매 수업의 정리 노트를 노션 MCP와 Claude를 활용해 작성할 계획입니다. 본 페이지가 그 첫 번째 결과물입니다. |
| 문제가 생겼을 때 AI와 함께 해결하는 방식이 효과적이었습니다. 집에서 CLI 설치와 노션 연결 오류가 있었으나 AI와 협업하며 해결했습니다. | 새 파일과 폴더를 만들어 처음부터 구성하는 작업이 익숙하지 않았습니다. 그동안 API 호출 위주로만 코딩해 왔기 때문에 로컬 환경 기반 작업이 낯설었습니다. | 수업 전에 미리 할 수 있는 세팅은 사전에 마쳐 두려고 합니다. 안티그래비티 설치와 Claude 로그인에 예상보다 많은 시간이 소요되었습니다. |
| 이해가 되지 않거나 확실하지 않은 내용은 웹 자료로 2차 검증했습니다. (Part 1 팩트체크 참조) | Claude Code와 노션 사용법이 아직 익숙하지 않습니다. | 이후 새롭게 Claude를 세팅할때는 Claude 전용 폴더에서 새로 시작하고, 로그인은 시크릿 창에서 진행해 오류를 방지하려고 합니다. |
| | | 수업에서 소개된 슬라이드 생성 Skill을 활용해 간단한 슬라이드 자동화 프로그램을 만들어 보고자 합니다. |

### AAR (After Action Review)

| 질문 | 답변 |
|---|---|
| 원래 목표는 무엇이었는가 | 널리 알려진 Claude Code의 사용법을 배우는 것이 목표였습니다. |
| 실제 결과는 어떠했는가 | 이전에 안티그래비티로 코딩을 해 본 경험이 있어 수업 자체는 비교적 쉽게 느껴졌습니다. 다만 MCP 활용법과 Skill 생성법은 처음 접하는 내용이어서 유익했습니다. 배운 내용을 바로 적용하여 본 정리 노트를 노션 MCP로 작성했습니다. |
| 차이가 발생한 이유는 무엇인가 | 기본 사용법은 안티그래비티 경험 덕분에 익숙했으나, 로그인·환경 세팅·파일 기반 작업은 처음이라 막히는 부분이 있었습니다. API 호출 위주로만 코딩해 온 습관 때문에 로컬 환경 구성이 낯설었던 것이 원인이라고 판단합니다. |
| 다음에는 무엇을 다르게 할 것인가 | 전용 폴더에서 처음부터 시작하고, 시크릿 창에서 로그인하며, 설치와 로그인은 수업 전에 미리 마쳐 두겠습니다. 또한 이번 경험을 통해 목표가 명확하다면 AI와 협업하여 해결하지 못할 문제는 없다는 점을 느꼈으므로, 막히더라도 우선 시도해 보는 태도를 유지하겠습니다. |

## 2. 적용 방법

### 2-1. 강의 내용을 직접 적용한 실습

#### 실습 1. Claude Code 환경 세팅

| 단계 | 내용 | 결과 |
|---|---|---|
| 1 | Node.js 확인 → `npm install -g @anthropic-ai/claude-code` 로 CLI 설치 | ✅ v2.1.273 |
| 2 | 터미널에서 `claude` 실행 → 테마 선택 → Claude.ai 구독 계정 로그인 | ✅ |
| 3 | VS Code 익스텐션도 병행 사용 | ✅ |

**막혔던 부분 & 해결**

- `/mcp`를 PowerShell에 바로 입력 → 오류. `/mcp`는 **Claude CLI 안에서** 입력하는 명령
- `claude` 명령 인식 안 됨 → CLI 미설치 상태였음. npm으로 전역 설치 후 **새 터미널** 열어야 PATH 반영

#### 실습 2. Notion MCP 연결

| 단계 | 내용 | 결과 |
|---|---|---|
| 1 | 프로젝트 폴더에 `.mcp.json` 생성 (`https://mcp.notion.com/mcp`) | ✅ |
| 2 | CLI에서 `/mcp` → `notion` → `Authenticate` | ✅ |
| 3 | 브라우저에서 노션 로그인 → 워크스페이스 접근 허용 | ✅ |
| 4 | 강의 녹음 전사본(txt 3개) → Claude Code로 정리 → 노션 페이지 자동 생성 | ✅ 이 문서 |

**막혔던 부분 & 해결**

- 노션 로그인 화면에서 `403` + `sw.js Failed to fetch` 오류 → 노션 웹 자체 서비스워커 문제. 재시도로 해결
- 인증 **전에 시작한** 세션에는 노션 도구가 로드되지 않음 → 새 세션 열거나 `claude -p`로 우회

**강의에서 배운 것을 그대로 적용한 지점**

- 강사가 시연한 "파일 첨부 + 노션 링크 → 정리해줘" 워크플로우(Part 1 §9)를 그대로 재현
- MCP 보안 주의(§11): Notion 공식 MCP 서버(`mcp.notion.com`)만 사용

#### 실습 3. GitHub MCP 연결 & 정리 노트 업로드

Claude(데스크톱 앱 Code 탭)와 대화하며 GitHub MCP를 연결하고, 노션에 정리한 이 특강 노트를 이 저장소에 올렸습니다.

| 단계 | 내용 | 결과 |
|---|---|---|
| 1 | Notion 연결 방식 점검 → 계정 단위 커넥터 대신 **프로젝트 폴더의 `.mcp.json`** 방식으로 정리 | ✅ |
| 2 | `.mcp.json`에 GitHub 공식 MCP 서버(`https://api.githubcopilot.com/mcp/`) 추가, 인증 헤더는 `Bearer ${GITHUB_PAT}` 환경변수 참조 | ✅ |
| 3 | GitHub Fine-grained PAT 발급 → Windows 사용자 환경변수 `GITHUB_PAT`에 저장 | ✅ |
| 4 | Claude가 노션 페이지를 MCP로 읽어 Markdown으로 변환 → `강의요약` / `느낀점_적용방법` 2개 파일로 분리 | ✅ |
| 5 | 저장소 `cv-special-lecture` 생성 → 같은 토큰으로 `git push` | ✅ 이 저장소 |

**막혔던 부분 & 해결**

- 처음 연결한 **claude.ai 계정 커넥터**는 계정 단위라서, 같은 계정으로 로그인한 다른 기기에서도 내 노션에 접근 가능 → 공용 계정일 경우 위험하다고 판단해 해제하고, 토큰이 **이 PC에만 저장되는** `.mcp.json` 방식으로 전환
- 토큰을 **채팅창에 그대로 붙여넣는 실수** → 대화 기록에 남아 노출된 것으로 보고 즉시 폐기 후 재발급. 이후에는 환경변수 편집 창에서만 입력
- `.mcp.json`에 토큰을 직접 쓰지 않고 `${GITHUB_PAT}`로 참조 → 폴더가 OneDrive로 동기화돼도 토큰은 노출되지 않음
- 환경변수 저장 후에도 도구가 안 보임 → 앱이 켜진 상태에서 저장했기 때문. 앱을 **완전히 재시작**해야 반영됨
- 저장소 생성 `403 Resource not accessible by personal access token` → 토큰에 저장소 생성 권한이 없음. 빈 저장소는 GitHub 웹에서 직접 생성
- `git push` `403` → 토큰의 Repository access가 **"Public repositories"(읽기 전용)** 로 되어 있었음. **Only select repositories → `cv-special-lecture`** 선택 + **Contents: Read and write** 권한 추가로 해결

**강의에서 배운 것을 그대로 적용한 지점**

- MCP 보안 주의(§11)를 실제 설정에 반영: 공식 서버만 사용, 토큰은 **필요한 저장소 1개 + 필요한 권한 1개(Contents)** 로 최소화, 만료 기간 설정
- "All repositories"도 고려했지만, 에이전트가 늘 쓰는 토큰이라 잘못 동작하거나 유출될 경우 피해 범위를 줄이기 위해 **저장소 1개만** 허용

### 2-2. 앞으로의 적용 계획

- 수업에서 소개된 슬라이드 생성 Skill을 발전시켜 간단한 슬라이드 자동화 프로그램을 만들어 볼 계획입니다.
- 진로에 대한 고민은 여전히 남아 있습니다. 교수님의 조언에 따라 우선 여러 가지를 직접 시도해 보면서 방향을 찾아가고자 합니다.
